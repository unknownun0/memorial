# How to Make a Scope of Work

## The 5-Step Process

### 1. Map the Project
Open every file, read the first few lines, write one sentence per file about what it does. Group related files together.

### 2. Describe Each Piece
For every section/feature, answer: What is it? Where is it? What does it show? How does it work? What needs changing? Use tables.

### 3. Spot the Gaps
Look for sample data (Pinterest images, John Doe, Lorem Ipsum), placeholder text ("Coming soon"), and missing setup (email not configured, no domain). Write each gap as a task.

### 4. Add Testing & Roles
List everything that could break (links, forms, mobile view, browsers). Write who does what (owner provides content, developer codes).

### 5. Use the Template

```
# [Project Name] — Scope of Work

## 1. Summary
One sentence: what, who, why.

## 2. Sections
| Section | File | What It Shows | Needs Changing |
|---------|------|--------------|---------------|

## 3. Features
| Feature | File | How It Works | Status |
|---------|------|-------------|--------|

## 4. Tech Stack
Tool → What it does

## 5. Tasks (Phased)
☐ Phase 1 tasks
☐ Phase 2 tasks

## 6. Testing
☐ Test items

## 7. Future Ideas
- Idea

## 8. Roles
Person → Responsibility
```

### Golden Rule
Explain everything like you're talking to someone who doesn't know technology. No jargon. Short sentences. Tables over paragraphs.
